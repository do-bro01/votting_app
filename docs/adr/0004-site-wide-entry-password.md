# 앱 전체를 입장 비밀번호 하나로 막고, 들어온 구성원은 모두 같은 권한을 가진다

ADR-0003은 운영자만 비밀번호로 가리고 투표·결과는 공개했다(수업자료의 교수님 버전과 같은 방향). 실제로 쓰려는 곳은 "우리끼리만" 쓰는 동아리라 외부인이 질문이나 결과를 보는 것 자체를 막고 싶었고, 비밀번호를 둘로 나누면(구성원용·운영자용) 환경변수와 공유할 값이 늘어나 동아리 규모에 비해 무겁다. 그래서 환경변수 `ADMIN_TOKEN`의 입장 비밀번호 하나로 앱 전체(목록·투표하기·결과·만들기·삭제와 모든 API)를 막고, 입력한 사람은 모두 같은 권한의 구성원으로 본다. 대가로 비밀번호를 아는 구성원은 누구나 남의 투표도 삭제할 수 있다. 세션 방식(브라우저를 닫으면 풀리는 쿠키, 쿠키에는 비밀번호로 만든 서명값, 비밀번호를 바꾸면 모든 세션 무효)은 ADR-0003을 그대로 잇는다. 검사는 모든 요청 앞의 Proxy(`proxy.ts`)가 화면은 입장 화면으로 보내고 API는 401로 거부하며, 쓰기·읽기 API는 Proxy와 별개로 각 Route Handler에서도 다시 확인한다. 표는 여전히 누가 던졌는지 기록하지 않고 중복도 막지 않는다(ADR-0001).
