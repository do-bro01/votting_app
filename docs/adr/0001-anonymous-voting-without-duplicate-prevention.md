# v1은 로그인 없는 익명 투표이며 중복 투표를 막지 않는다

v1에서는 투표를 만드는 사람도, 표를 던지는 투표자도 로그인하지 않는다. 한 사람이 같은 투표에 여러 번 표를 던지는 것도 막지 않는다. 쿠키로 가볍게 막는 방법도 검토했지만 시크릿 창으로 쉽게 우회할 수 있어 신뢰성을 거의 높이지 못한다. 그래서 "질문을 올리면 사람들이 골라서 투표하고 결과를 본다"는 요청 범위를 지키는 단순함을 택했다. 누구나 투표를 만들 수 있으므로, 남의 투표를 지우거나 이미 받은 표의 의미가 바뀌는 일을 막기 위해 만든 투표는 수정·삭제할 수 없다. 공식 선거처럼 신뢰성이 필요해지면 투표자 신원 확인과 중복 방지를 별도 버전에서 추가한다.
