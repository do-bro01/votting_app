# 운영자는 개인 계정 대신 공유 비밀번호 하나로, 브라우저 세션 동안만 인정한다

투표(Poll)는 운영자만 만들 수 있다(ADR-0001의 "누구나 투표를 만든다"를 대체). 운영자는 계정을 따로 두지 않고, 환경변수 `ADMIN_TOKEN`에 담긴 공유 비밀번호 하나를 아는 사람으로 정의한다. 동아리 규모에서는 계정·회원가입이 주는 이득(운영자 구분, 개별 권한 회수)보다 구현·운영 비용이 크고, 수업 배포 가이드도 이 환경변수 하나를 전제로 하기 때문이다. 비밀번호를 맞히면 브라우저가 닫힐 때까지 유지되는 세션 쿠키를 발급하며, 쿠키에는 비밀번호 자체가 아니라 비밀번호에서 유도한 서명값을 담는다. 투표자는 여전히 익명이고 중복 투표도 막지 않는다(ADR-0001 유지). 비밀번호가 새면 `ADMIN_TOKEN`을 바꾸는 것으로 모든 운영자 세션이 한꺼번에 무효가 되며, 운영자별 계정이 필요해지면 이 결정을 다시 연다.
