# 01: 운영자 로그인과 나가기

**What to build:** 운영자가 `/login`에서 운영자 비밀번호를 입력해 로그인하면 브라우저를 닫을 때까지 운영자로 인정되고, 상단 메뉴가 "투표 만들기" + "나가기"로 바뀐다. "나가기"를 누르면 로그아웃되어 상단이 "운영자 로그인"으로 돌아간다. 이 티켓은 운영자 세션 모듈, 로그인·로그아웃 API, 로그인 화면, 상단 메뉴를 만든다. 투표 만들기 보호는 02에서 한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 로그인 전 상단에 "운영자 로그인"만 보이고 "투표 만들기"·"나가기"는 없다
- [ ] 틀린 비밀번호 → "비밀번호가 올바르지 않습니다.", 빈 비밀번호 → "비밀번호를 입력해 주세요.", 화면 유지
- [ ] 비밀번호 입력칸은 가려진다(password 타입)
- [ ] 맞는 비밀번호 → 기본은 `/`로, `next`가 있으면 그 경로로 이동하고 상단에 "투표 만들기"·"나가기"
- [ ] `next`가 외부 주소(`https://…`, `//…`)면 무시하고 `/`로
- [ ] 발급된 쿠키는 만료가 없는 세션 쿠키이고 httpOnly이며 값에 비밀번호가 그대로 들어 있지 않다
- [ ] "나가기" → `/`로 이동, 상단이 로그인 전 상태
- [ ] `POST /api/operator/login`: 빈 값·형식 오류 400, 틀림 401, 맞음 200
- [ ] 테스트 하네스가 setup 단계에서 로그인한 저장 상태를 만들고, `.env.local`에 `ADMIN_TOKEN`이 있다
