# 02: 투표 만들기를 운영자만

**What to build:** 로그인하지 않은 사람이 투표 만들기 화면에 들어가면 로그인 화면으로 보내지고, 로그인하면 투표 만들기 화면으로 돌아온다. 투표 만들기 API를 직접 호출해도 운영자가 아니면 401로 거부되고 아무것도 저장되지 않는다. 투표하기·결과 보기는 지금처럼 누구나 쓴다.

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 비로그인으로 `/new` → `/login?next=/new`, 로그인 후 `/new`로 복귀
- [x] 비로그인 `POST /api/polls` → 401 `{ error }`, 투표가 저장되지 않는다
- [x] 첫 화면의 빈 목록 안내의 만들기 링크는 운영자에게만 보인다
- [x] 비로그인 투표자가 표를 던지고 결과를 볼 수 있다
- [x] 운영자로 기존 투표 만들기 테스트(마감 시각 포함)가 모두 통과한다
