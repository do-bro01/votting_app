# 03: 운영자의 투표 삭제

**What to build:** 운영자는 투표하기 화면에서 "투표 삭제"를 눌러 확인 단계를 거친 뒤 투표를 지울 수 있다. 지우면 선택지와 표도 함께 사라지고 목록으로 돌아가며, 목록에서 그 투표가 없어진다. 로그인하지 않은 사람에게는 버튼이 보이지 않고, 삭제 API도 401로 거부된다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 운영자에게만 투표하기 화면에 "투표 삭제" 버튼이 보인다
- [ ] "투표 삭제" → 확인 문구와 "삭제"·"취소". "취소"는 아무것도 지우지 않는다
- [ ] "삭제" → 목록으로 이동, 목록에서 사라짐, 투표하기·결과 주소는 "투표를 찾을 수 없습니다"
- [ ] 선택지도 DB에서 함께 삭제된다
- [ ] 마감된 투표도 삭제할 수 있다
- [ ] 비로그인 `DELETE /api/polls/[id]` → 401, 투표는 남아 있다. 없는 투표·uuid 아닌 id → 404
