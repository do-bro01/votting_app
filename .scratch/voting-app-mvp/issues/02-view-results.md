# 02: 결과 보기

**What to build:** 누구나 투표 여부와 상관없이 `/polls/[id]/results`에서 질문, 선택지별 득표수와 퍼센트(정수 반올림), 전체 표 수를 숫자 리스트로 본다. 표가 0개면 "아직 투표가 없습니다"와 모든 선택지 0표·0%가 보인다. 결과 화면에서 투표하기 화면과 목록으로 돌아갈 수 있고, 투표하기 화면에서도 결과 화면으로 갈 수 있다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 새로 만든 투표의 결과 화면에 모든 선택지가 입력 순서대로 0표·0%로 보이고 "아직 투표가 없습니다"가 보인다
- [ ] 전체 표 수가 보인다
- [ ] 득표수가 있는 투표에서 퍼센트가 정수 반올림으로 보인다 (테스트는 DB에 득표수를 직접 넣어 검증)
- [ ] 결과 화면 ↔ 투표하기 화면 ↔ 목록 링크가 동작한다
- [ ] 없는 투표·uuid가 아닌 id의 결과 주소는 "투표를 찾을 수 없습니다"
