# 03: 표 던지기

**What to build:** 투표자(Voter)가 로그인 없이 투표하기 화면에서 선택지 하나를 골라 제출하면, 그 선택지의 득표수가 1 늘고 곧바로 결과 화면으로 이동해 반영된 결과를 본다. 여러 사람이 동시에 투표해도 표가 사라지지 않는다. 중복 투표는 막지 않는다(ADR-0001).

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 선택지 하나를 골라 제출하면 결과 화면으로 이동하고 해당 선택지가 1표·100%로 보인다
- [ ] 선택지는 하나만 고를 수 있고, 아무것도 고르지 않고 제출하면 안내 문구가 나온다
- [ ] `POST /api/polls/[id]/vote`에 다른 투표의 선택지 id나 없는 선택지 id를 보내면 400, 없는 투표면 404
- [ ] 같은 선택지에 동시에 여러 표(예: 10개)를 API로 보내면 모두 반영된다
- [ ] 득표수는 DB 안에서 원자적으로 증가한다
