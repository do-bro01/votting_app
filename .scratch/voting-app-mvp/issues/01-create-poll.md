# 01: 투표 만들기 (스키마 + 테스트 하네스 + 목록 + 투표하기 화면 표시)

**What to build:** 누구나 `/new`에서 질문과 선택지 2~5개로 투표(Poll)를 만들고, 만든 직후 그 투표의 투표하기 화면에서 질문과 선택지를 입력 순서대로 본다. 첫 화면 `/`에는 모든 투표가 최신순으로 보이고 각 투표에서 투표하기·결과 보기로 갈 수 있다. 이 티켓이 스키마(`polls`, `options`)를 개발 Neon DB에 만들고, 투표 데이터 모듈과 Playwright 테스트 하네스(`npm run test`, 테스트가 만든 투표는 끝나고 삭제)를 처음 세운다. 투표하기 화면은 이번 티켓에서 질문과 선택지를 보여주기만 하고, 표 제출은 03에서 한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 스키마 SQL이 저장소에 파일로 있고 개발 DB에 실행되어 있다
- [ ] `npm run test`로 Playwright E2E가 실행되고, 테스트가 만든 투표는 끝나면 삭제된다
- [ ] `/new`에서 질문 + 선택지 2개로 투표를 만들면 `/polls/[id]`로 이동해 질문과 선택지가 입력 순서대로 보인다
- [ ] 선택지 입력칸은 처음 2개, 최대 5개까지 추가, 2개 미만으로는 삭제 불가
- [ ] 빈 질문, 빈 선택지, 중복 선택지(공백 제거 후 비교)는 폼에서 이유와 함께 거부된다
- [ ] `POST /api/polls`를 직접 호출해도 같은 규칙(빈칸, 중복, 2~5개)이 400으로 거부된다
- [ ] 저장값은 앞뒤 공백이 제거되어 있고, 투표와 선택지는 한 번에 저장된다
- [ ] `GET /api/polls/[id]`가 질문과 순서대로 정렬된 선택지를 돌려주고, 없는 id·uuid가 아닌 id는 404
- [ ] `/`에 새 투표가 최신순으로 보이고 투표하기·결과 보기 링크가 있다. 투표가 없으면 안내 문구와 만들기 링크
- [ ] 없는 투표의 `/polls/[id]`는 "투표를 찾을 수 없습니다"
