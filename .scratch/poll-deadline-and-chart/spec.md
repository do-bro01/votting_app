# Spec: 투표 마감 시각 + 결과 그래프

Status: ready-for-agent

## Problem Statement

동아리 회장에 따르면 투표가 마감 없이 계속 열려 있어서 사람들이 참여를 미루다가 결국 참여하지 않는다. 또 결과가 숫자 리스트뿐이라 어느 선택지가 앞서는지 한눈에 들어오지 않는다.

## Solution

투표(Poll)를 만들 때 마감 시각(Closing Time)을 선택적으로 정할 수 있게 한다. 마감 시각이 지나면 그 투표는 마감된 투표(Closed Poll)가 되어 투표하기 화면에서 선택지와 버튼이 비활성화되고 "마감된 투표입니다"가 보이며, 서버도 표(Vote)를 거부한다. 결과(Results) 화면은 숫자 리스트 대신 선택지별 퍼센트 가로 막대 그래프와 득표수, 전체 표 수를 보여준다. 마감 시각이 없는 기존 투표는 지금처럼 무기한 열려 있다.

## User Stories

### 마감 시각 정하기
1. 투표를 올리는 사람으로서, 투표를 만들 때 마감 시각을 선택적으로 입력하고 싶다. 그래야 참여 기한을 알릴 수 있다.
2. 투표를 올리는 사람으로서, 마감 시각을 비워 두면 투표가 무기한 열려 있기를 원한다.
3. 투표를 올리는 사람으로서, 지금보다 이전 시각을 마감 시각으로 넣으면 "마감 시각은 지금 이후여야 합니다."로 거부되기를 원한다. 그래야 만들자마자 마감된 투표가 생기지 않는다.
4. 투표를 올리는 사람으로서, 마감 시각을 내 컴퓨터의 현지 시각으로 입력하고 싶다.
5. 운영 관점에서, API를 직접 호출해도 과거 마감 시각이나 형식이 잘못된 마감 시각은 400으로 거부되기를 원한다.

### 마감 전 투표
6. 투표자로서, 마감 시각이 있는 투표의 투표하기 화면에서 "마감: <한국 시간>"을 보고 싶다. 그래야 언제까지 투표할 수 있는지 안다.
7. 투표자로서, 마감 전이면 지금처럼 표를 던질 수 있기를 원한다.
8. 투표자로서, 목록에서 마감 시각이 있는 투표는 "마감: <한국 시간>"을 보고 싶다.

### 마감 후
9. 투표자로서, 마감된 투표의 투표하기 화면에서 "마감된 투표입니다"를 보고 싶다.
10. 투표자로서, 마감된 투표의 선택지와 투표하기 버튼이 숨겨지지 않고 비활성화되어 있기를 원한다. 그래야 어떤 선택지가 있었는지 볼 수 있다.
11. 투표자로서, 마감된 투표에서도 결과 보기로 갈 수 있기를 원한다.
12. 운영 관점에서, 마감된 투표에 API로 표를 던지면 서버가 409로 거부하고 득표수가 늘지 않기를 원한다. 그래야 화면 검사를 우회해도 마감이 지켜진다.
13. 투표자로서, 투표하기 화면을 열어 둔 사이에 마감되어 제출이 거부되면 "마감된 투표입니다" 안내를 보고 싶다.
14. 투표자로서, 목록에서 마감된 투표에 "마감됨" 표시를 보고 싶다.
15. 누구나, 마감된 투표의 결과 화면에서 "마감된 투표입니다"를 보고 싶다.

### 기존 투표
16. 투표자로서, 마감 기능 이전에 만든(마감 시각 없는) 투표가 지금처럼 동작하기를 원한다.

### 결과 그래프
17. 누구나, 결과 화면에서 선택지별 퍼센트를 가로 막대 길이로 보고 싶다. 그래야 어느 선택지가 앞서는지 한눈에 안다.
18. 누구나, 막대 옆에서 선택지 이름, 득표수, 퍼센트(정수 반올림)를 함께 보고 싶다.
19. 누구나, 전체 표 수를 보고 싶다.
20. 누구나, 표가 0개인 투표에서도 그래프가 깨지지 않고 모든 막대가 0 길이로, "아직 표가 없습니다"와 함께 보이기를 원한다.
21. 누구나, 동률인 선택지들의 막대 길이가 같기를 원한다.
22. 스크린리더 사용자로서, 막대가 아닌 텍스트(선택지, 득표수, 퍼센트)로 결과를 읽을 수 있기를 원한다.

## Implementation Decisions

- **용어**: CONTEXT.md의 마감 시각(Closing Time), 마감된 투표(Closed Poll)를 코드·UI·테스트에 쓴다.
- **ADR 준수**: ADR-0001(수정 불가 — 마감 시각도 만든 뒤 바꿀 수 없음), ADR-0002(raw SQL, SQL은 투표 데이터 모듈에만).
- **스키마 변경**: `polls`에 nullable 마감 시각 컬럼 추가. 기존 행은 null(무기한).

  ```sql
  alter table polls add column if not exists closes_at timestamptz;
  ```

  마이그레이션 SQL은 저장소에 파일로 남기고 `db/schema.sql`에도 반영한다. Neon SQL Editor 또는 SQL 적용 스크립트로 실행한다.
- **마감 판단은 DB 시각 기준**: "마감되었는가"는 `closes_at is not null and closes_at <= now()`로 DB에서 판단한다. 서버·브라우저 시계 차이에 흔들리지 않게 한다.
- **표 던지기 원자성**: 득표수 증가 쿼리 자체에 "투표가 마감되지 않았음" 조건을 넣어, 마감 확인과 증가 사이에 마감되는 경쟁 상황에서도 마감 후 표가 들어가지 않게 한다. 반영된 행이 없으면 원인을 가려 "투표 없음(404) / 마감됨(409) / 선택지 불일치(400)"로 응답한다. 마감된 투표에 잘못된 선택지를 보내면 마감(409)을 먼저 알린다. (code-review에서 확정)
- **투표 데이터 모듈 인터페이스 변경**
  - 투표 만들기 입력에 선택적 마감 시각(ISO 8601 문자열 또는 null/생략)을 받는다.
  - 투표 목록·투표 하나·결과 조회는 마감 시각(ISO 문자열 또는 null)과 마감 여부를 함께 돌려준다.
  - 표 던지기 결과에 "마감됨"이 추가된다.
- **검증 규칙 추가**: 마감 시각은 생략/null/빈 문자열이면 없음. 값이 있으면 시간대(Z 또는 ±hh:mm)가 붙은 ISO 8601 문자열이고, 달력에 있는 날짜(예: 2월 31일 불가)여야 하며, 서버 현재 시각 이후여야 한다. (code-review에서 시간대 필수·실제 날짜 검사 추가) 폼도 같은 규칙으로 미리 안내하되 서버가 기준이다.
- **API 변경**
  - `POST /api/polls` body에 선택적 `closesAt: string | null` 추가 → 과거·형식 오류는 400
  - `GET /api/polls/[id]` 응답에 `closesAt: string | null`, `isClosed: boolean` 추가
  - `POST /api/polls/[id]/vote` → 마감된 투표면 409 `{ error: "마감된 투표입니다." }`
- **시간 입력·표시**: 폼은 `datetime-local`로 현지 시각을 받고, 브라우저에서 ISO(UTC)로 바꿔 보낸다. 화면 표시는 서버에서 한국 시간(Asia/Seoul)으로 "YYYY. M. D. 오후 h:mm" 형태로 포맷한다.
- **결과 그래프**: 차트 라이브러리 없이 선택지마다 한 줄씩, 선택지 이름·득표수·퍼센트 텍스트와 그 아래 퍼센트 폭의 가로 막대를 그린다. 막대는 장식(aria-hidden)이고 정보는 텍스트로 전달한다. 퍼센트 계산(정수 반올림, 0표면 0%)은 기존 결과 조회를 그대로 쓴다.

## Testing Decisions

- **기존 테스트 경계 그대로: Playwright E2E 하나.** 겉으로 보이는 동작만 검증한다.
- **마감된 투표 만들기**: 앱은 과거 마감 시각을 거부하므로, 테스트는 미래 마감 시각으로 투표를 만든 뒤 DB에서 `closes_at`을 과거로 바꿔 마감 상태를 만든다(기존 결과 테스트가 득표수를 DB에 직접 넣는 방식과 같음).
- **시나리오**: 폼에서 마감 시각 입력 → 투표하기 화면과 목록에 한국 시간 표시; 마감 시각 없이 만든 투표는 표시 없음·정상 투표; 과거 마감 시각 폼·API 거부; 형식 오류 API 거부; 마감된 투표의 투표하기 화면 비활성화 + 문구; 마감된 투표에 API 표 → 409, 득표수 불변; 화면을 연 뒤 마감되어 제출 거부 시 안내; 목록 "마감됨"; 결과 화면 "마감된 투표입니다"; 그래프 막대 폭이 퍼센트와 일치(0표 0%, 동률 같은 폭); `GET /api/polls/[id]`의 `closesAt`, `isClosed`.
- **선행 사례**: `e2e/create-poll.spec.ts`, `e2e/results.spec.ts`(DB 직접 조작 헬퍼), `e2e/cast-vote.spec.ts`.

## Out of Scope

- 만든 뒤 마감 시각 수정·연장, 수동 조기 마감
- 마감 알림, 남은 시간 카운트다운
- 원형 등 다른 그래프 종류, 차트 라이브러리
- 결과 실시간 갱신
- 마감 전 결과 숨기기
