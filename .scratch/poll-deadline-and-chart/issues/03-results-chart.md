# 03: 결과 그래프 (퍼센트 가로 막대)

**What to build:** 결과 화면이 숫자 리스트 대신 선택지별 퍼센트 가로 막대 그래프를 보여준다. 막대 옆에 선택지 이름·득표수·퍼센트, 아래에 전체 표 수. 표가 0개여도 깨지지 않는다. DB 변경 없음.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 선택지마다 퍼센트 폭의 가로 막대가 있다 (예: 1·2·0표 → 33%·67%·0%)
- [x] 0표 투표는 모든 막대 폭 0%이고 "아직 표가 없습니다"가 보이며 에러가 없다
- [x] 동률 선택지의 막대 폭이 같다
- [x] 막대는 aria-hidden 장식이고 선택지·득표수·퍼센트는 텍스트로 읽힌다
- [x] 기존 결과 테스트(득표수·퍼센트·전체 표 수 텍스트)가 계속 통과한다
