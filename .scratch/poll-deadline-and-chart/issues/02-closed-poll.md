# 02: 마감된 투표 막기 (화면 비활성화 + 서버 거부)

**What to build:** 마감 시각이 지난 마감된 투표(Closed Poll)는 투표하기 화면에서 선택지와 버튼이 비활성화되고 "마감된 투표입니다"가 보인다. API로 표를 던져도 서버가 409로 거부하고 득표수는 늘지 않는다. 화면을 열어 둔 사이 마감되어 제출이 거부되면 안내가 보인다. 목록에는 "마감됨", 결과 화면에는 "마감된 투표입니다"가 보인다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 마감된 투표의 투표하기 화면: "마감된 투표입니다", 라디오·버튼 disabled(숨기지 않음), 결과 보기 링크 유지
- [ ] 마감된 투표에 `POST /api/polls/[id]/vote` → 409, 득표수 불변
- [ ] 화면을 연 뒤 마감되어 제출하면 폼에 "마감된 투표입니다."가 보인다
- [ ] 목록에 "마감됨", 결과 화면에 "마감된 투표입니다"
- [ ] 마감 확인과 득표수 증가가 한 쿼리에서 원자적으로 일어난다
